# Modelos de entrega da Godois

Para transformar uma nota da Sexta-Feira em algo que vai para o cliente ou para o público.

| Entrega | Modelo | Observação |
|---|---|---|
| Parecer / orientação técnica | `Parecer.md` | Linguagem para o cliente; fundamento no rodapé |
| E-mail ou WhatsApp ao cliente | `Mensagem ao cliente.md` | Curto, com ação clara |
| Conteúdo (Instagram, LinkedIn, site) | `Conteúdo.md` | Usar as skills de carrossel e do site da Godois |
| Contrato | — | Usar a skill de contrato padrão da Godois |

Regras: identidade visual e tom da Godois; nada de dado de outro cliente; tema jurídico para cliente com a observação de procurar advogado quando couber; revisão final do João antes de enviar.
